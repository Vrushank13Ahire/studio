# Perihelion — Digital Studio

> Digital experiences, built with intent.

Perihelion is an independent digital studio focused on designing and developing modern, lightweight and memorable websites for businesses, creators, startups and individuals.

The studio focuses on combining strong visual direction with clean frontend development to create digital experiences that are simple, responsive and purposeful.

---

## ✦ About

VANTA/01 is built around a simple idea:

**Good websites don't just exist. They create an impression.**

Instead of relying on heavy frameworks, unnecessary dependencies or template-driven design, VANTA/01 focuses on:

- Strong visual identity
- Thoughtful layouts
- Responsive experiences
- Lightweight development
- Smooth interactions
- Performance
- Attention to detail

---

## ✦ Website

The VANTA/01 website acts as the studio's digital presence and portfolio.

It introduces the studio, showcases selected work, explains the services offered and provides a way for potential clients to start a project.

## ✦ Technology

The website intentionally uses a lightweight technology stack.

| Technology | Purpose |
|---|---|
| HTML5 | Structure and semantic markup |
| CSS3 | Layout, visual design and animations |
| Vanilla JavaScript | Interactions and dynamic behavior |

### No unnecessary frameworks

This project does **not** use:

- React
- Vue
- Angular
- Tailwind CSS
- Bootstrap
- jQuery
- Three.js
- Backend frameworks
- Database systems

The goal is to keep the website lightweight, maintainable and fast.

---

## ✦ Design Direction

VANTA/01 follows a dark, cinematic and experimental visual language.

The design is influenced by:

- Digital art
- 3D forms
- Technical structures
- Perspective
- Editorial typography
- Minimal interfaces
- Digital fabrication
- Motion and interaction

The primary visual concept is a **digital construction object** — representing the process of designing and building digital experiences.

The interface intentionally avoids common SaaS and AI-generated design patterns.

## ✦ Typography

The website uses a three-level typography system:

### Display
**Space Grotesk**

Used for major headlines and visual statements.

### Body
**Inter**

Used for descriptions, paragraphs and interface content.

### Utility
**IBM Plex Mono**

Used for labels, metadata and technical details.
